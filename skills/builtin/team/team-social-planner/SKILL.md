# Team Social Media Planner

Plan, draft, and schedule social media content for CentaurAI brand presence across platforms.

## Overview

Structured content calendar with multi-platform copy adaptation for WeChat Official Account, Twitter/X, and Xiaohongshu. Calendar at ~/团队/社媒/日历-YYYY-MM.md.

## When to Use

- Plan monthly social media content
- Draft a WeChat article about a new release
- Write a Twitter thread announcing features
- Adapt content for different platforms
- Generate a content calendar

## Content Strategy

### Brand Voice by Platform

| Platform | Tone | Content Mix | Frequency |
|----------|------|-------------|-----------|
| 公众号 | Professional + approachable | Product updates, tech deep-dives, case studies | 1-2/week |
| Twitter/X | Concise + technical | Product news, industry takes, engagement | 3-5/week |
| 小红书 | Visual + tutorial | How-tos, results showcase, behind-the-scenes | 2-3/week |

### Content Pillars

1. Product updates (30%) - New features, releases, tips
2. Technical insights (25%) - AI knowledge, best practices, optimization
3. Customer cases (20%) - Use scenarios, results, interviews
4. Company updates (15%) - Team culture, hiring, events
5. Industry views (10%) - AI trends, competitor analysis

## Content Calendar Template

```
~/团队/社媒/日历-YYYY-MM.md

Each week: date, platform, content type, topic, status
Status flow: 选题 -> 草稿 -> 审核 -> 已发
Maintain an idea pool at the bottom
```

## Platform Writing Guides

### WeChat Official Account (公众号)
- 1500-3000 characters, sub-headers every 300-500 chars
- Leading summary (2-3 sentences) to hook readers
- Visual breaks: pull quotes for actionable tips
- End with: follow CTA, related articles, QR code

### Twitter/X
- Thread format: 4-8 tweets, first tweet standalone
- 2-3 hashtags max
- Include image/screenshot
- Each tweet makes sense independently

### 小红书
- Cover image is most important (50% of effort)
- Title: emoji + number + pain point
- Conversational tone, like sharing with friends
- 5-10 hashtags, mix broad and niche
- 3-9 images, 1:1 or 3:4 ratio

## Content Workflow

1. Ideation: source from roadmap, customer questions, industry news
2. Draft: markdown in ~/团队/社媒/草稿/
3. Review: second team member checks
4. Publish: use wechat-marketing for 公众号, xurl for Twitter
5. Track: fill performance data after 48h

## Monthly Review

- Top 3 performing posts and why
- Bottom 3 and lessons
- Follower growth trend
- Content mix balance check
- Best posting times

## Common Pitfalls

1. All product, no value - follow 80/20 rule
2. Copy-paste across platforms - adapt per platform
3. Inconsistent posting - use calendar for rhythm
4. No engagement - reply within 24h
5. Hashtag spam - 2-3 max on Twitter
6. No clear CTA - decide purpose before writing

## Verification Checklist

- Content calendar updated for current month
- Platform-specific copy adapted
- Images prepared for visual platforms
- Post timing optimized (公众号 best: 8am/noon/8pm)
- Second-person review completed
